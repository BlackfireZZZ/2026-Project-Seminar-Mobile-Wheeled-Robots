# Практическая работа 2 — TurtleBot3 в Webots

Пакет `practice02_webots` находится в `solution/`. Сцена содержит площадку
8 × 8 м, неподвижные серые цифры в отдельных PROTO-файлах и TurtleBot3.
Подготовлен вариант **02**. Робот стартует на окружности радиуса
2,5 м вокруг центра цифр. При указанных ниже скоростях полный круг занимает
примерно 79 секунд.

Чтобы использовать другой вариант, **перед сборкой** сгенерируйте сцену:

```bash
python3 ~/practices_ws/src/practice-02/solution/generate_scene.py 12
```

Замените `12` на свой вариант; для однозначного номера укажите ведущий ноль.
Генератор создаёт по одному PROTO-файлу для каждой уникальной цифры и обновляет
ссылки в мире. В пакет при сборке устанавливаются готовые `.wbt` и `.proto`.

В контейнере курса с Webots:

```bash
cd ~/practices_ws
colcon build --symlink-install --packages-select practice02_webots
source install/local_setup.zsh
ros2 launch practice02_webots number_world.launch.py
```

После запуска контроллера в другом терминале подайте постоянную команду:

```bash
ros2 topic pub -r 10 /cmd_vel geometry_msgs/msg/TwistStamped \
  '{twist: {linear: {x: 0.20}, angular: {z: 0.08}}}'
```

Остановите публикацию клавишами `Ctrl+C` после полного круга. Робот идёт
против часовой стрелки по окружности радиуса `v/ω = 2,5 м`; расстояния до
цифр и стен рассчитаны с запасом. Если движение в вашей версии контроллера
отличается, проверьте тип топика командой `ros2 topic type /cmd_vel`.
